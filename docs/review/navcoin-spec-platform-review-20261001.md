# NAVCoin Specification Platform Review, 2026-10-01

A correctness review of the validator-behaviour statements in
[the NAVCoin create-and-swap specification](../navcoins/navcoin-create-and-swap-spec.md)
against the deployed validator code.

- **Code reviewed:** `c93b2137` (`release/combined-fastpay-20260928`). `crates/execution`, `crates/types`, `crates/rpc_sdk` and `crates/nav_reserve_protocol` on `main` are identical to it. `main` differs from `c93b2137` only in seven `crates/node` snapshot and status files, none on the paths below. The node fee-quote line is cited at `c93b2137`.
- **Scope:** §3, §3.1, §3.2, §8.1–§8.5, §9.1, and the gate rows B1.3, B1.5, B2.5 and B2.6. Statements about off-chain services are included only where the specification attributes them to the validator, or where the validator constrains them.
- **Method:** reading the code only. No tests were run, and no host was touched.
- **Paths:** `exec/` is `crates/execution/src/`. `types/` is `crates/types/src/`. `nft` is `exec/nft_escrow_asset_execution.rs`, `vault` is `exec/nav_vault_asset_execution.rs` and `sp1` is `exec/nav_sp1_verifier.rs`.

## Summary

| Verdict | Count |
|---|---|
| Holds | 13 |
| Holds with a condition the specification does not state | 24 |
| Does not hold | 3 |
| Not implemented (planned item) | 4 |
| **Total** | **44** |

Most important rows:

- **R3, R36:** a paused route still accepts sells. `apply_pftl_uniswap_primary_redeem` deliberately skips the pause check. Pause blocks only buys, reservations and exports.
- **R15:** the fee quote no longer has a 4,096-byte limit for asset operations. The planned quote-by-proof-hash item, B2.2, therefore rests on a premise that no longer holds at `c93b2137`.
- **R22, R29:** the `sp1-nav-reserve-v1` bindings hold only while the asset stays bound to such a profile. The issuer can rebind an asset by calling `nav_asset_register` again. An asset whose `proof_profile` is not a registered profile ID gets no proof check at all.
- **R38:** a pre-signed pause expires when its key signs anything else, because asset transactions require the exact next sequence.
