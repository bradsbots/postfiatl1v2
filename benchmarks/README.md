# Benchmarks And Campaign Packets

> **Internal engineering record.** Each directory holds the inputs, harnesses
> and checksum-bound result packets of one benchmark or verification campaign,
> for example `cobalt-adversarial-verification` (campaign E1–E6) or
> `storage-scaling` (storage gates). Results are evidence for the claims in the
> docs, measured under the conditions each packet records; they are not live
> network state or service-level commitments.

The [Evidence Index](../docs/evidence/index.md) explains which packets support
which claims. Tests and verifiers read these paths, so do not move or rename
them.
