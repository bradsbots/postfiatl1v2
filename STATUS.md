# Post Fiat L1 Status

This file is kept as a pointer. Status lives in the docs so there is one place
to update:

- [Network Status](docs/status/network-status.md): one dated page with the
  running network, current release, height, quorum and what is still open.
- [Current State](docs/status/chain-state-current.md): the full, dated
  operating log (releases, rollouts, fleet observations, drills).
- [Release Gate Inventory](docs/status/release-gate-inventory.md) and
  [Testnet Path](docs/status/testnet-path.md): what must pass before a public
  testnet.
- [Security](docs/security/index.md): audit status and known limitations.

In short: the only running network is the controlled devnet
`postfiat-wan-devnet-2`, run by six Foundation-administered validators. It is
not a production mainnet and the code is not externally audited.
